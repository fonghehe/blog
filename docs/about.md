## 关于这个博客

这里收集前端开发中的学习笔记、技术整理与实践思路。文章以问题、适用条件和参考资料为线索，归档保留技术演进的上下文。

作者公开账号：[fonghehe](https://github.com/fonghehe)。博客源码与问题反馈：[GitHub 仓库](https://github.com/fonghehe/blog)。

## 内容维护说明 {#content-policy}

- 发布日期记录历史时间；后续修订以“更新于”单独标明，不把更新内容伪装成当年的结论。
- “验证于”仅在实际检查相关行为后填写；没有该字段不代表已经验证。版本字段说明文章讨论的范围。
- 归档文章可能使用旧版本或已变化的接口。使用前核对官方文档，不将历史示例直接当作当前生产方案。
- 教学代码、假设场景和实际经历应明确区分。生产稳定性或性能结论需要具体环境、方法与证据。
- 历史内容正在持续复核，部分文章仍存在重复表述、示例相关性与翻译质量问题；本次改进不代表全部文章已核验。

## 发现问题

欢迎在文章评论或 GitHub issue 中提供文章链接、具体段落、适用版本和官方参考。如果涉及安全问题，请勿在评论中公开密钥或个人数据。
