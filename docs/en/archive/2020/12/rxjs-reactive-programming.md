On RxJS reactive programming: many developers only operate at the API-call level. This post tries to look at the real problems and solutions from a production perspective.

## Basic Principles

Building on this, we can take it further:

```javascript
import { create } from 'zustand'
import { persist, devtools } from 'zustand/middleware'

const useStore = create(
  devtools(persist(
    (set, get) => ({
      user: null,
      theme: 'light',
      notifications: [],
      setUser: (user) => set({ user }),
      toggleTheme: () => set(s => ({
        theme: s.theme === 'light' ? 'dark' : 'light'
      })),
      unreadCount: () => get().notifications.filter(n => !n.read).length
    }),
    { name: 'app-store' }
  ))
)

```

This pattern is very useful in large projects and noticeably cuts maintenance cost.
