## このブログについて

フロントエンド開発の学習ノート、技術解説、実践の考え方をまとめています。課題、前提条件、参考資料を明確にし、アーカイブには技術の歴史的背景を残します。

公開プロフィール：[fonghehe](https://github.com/fonghehe)。ソースとフィードバック：[GitHub リポジトリ](https://github.com/fonghehe/blog)。

## 編集方針 {#content-policy}

- 公開日は元の時系列を残し、後の修正は更新日として分けます。後から得た知識を当時の知識として扱いません。
- 検証日は該当する動作を実際に確認した場合だけ記載します。記載がない記事は検証済みとは限りません。対象バージョンで適用範囲を示します。
- 過去の記事には古いバージョンや API が含まれます。利用前に現在の公式ドキュメントを確認してください。
- 学習用コード、仮定の場面、実体験を区別します。本番稼働や性能の主張には環境、方法、証拠が必要です。
- 過去記事の確認は継続中です。定型文、コード例の関連性、翻訳品質に課題が残っており、今回のサイト改善は全記事の検証完了を意味しません。

## 問題の報告

記事のコメントか GitHub issue に、記事 URL、該当箇所、バージョン、公式の参考資料を添えてください。認証情報や個人情報は公開しないでください。
