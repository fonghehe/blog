2020 年はすべてを変えた年でした。パンデミック、在宅勤務、不確実性……。同時に、技術の大きな飛躍の年でもありました。

## 技術面で

**Vue 3 正式版**

1 年以上待ちわびた正式版がついに登場しました。9 月のリリース以降、社内の新規プロジェクトでは Vue 3 + Vite の採用を始めています。Vue 2 + Webpack と比べて開発体験が格段に良く、特に起動速度の速さが際立っています。

Composition API に慣れると、本当に気持ちがいいです。ロジックの再利用が明確になり、TypeScript のサポートも良好です。ただ、エコシステムはまだ十分ではなく、Element Plus は Beta のまま、いくつかのコミュニティ製コンポーネントライブラリを使ってはいくつかの躓きがありました。

**Vite 1.0**

12 月にリリースされ、次のプロジェクトですべて採用することを決めました。60 秒かかっていた起動にさよならです。

**远程工作适应**

3 月から在宅になり、今に至るまで 9 ヶ月が経ちました。リモートワークのスタイルを受け入れ、少しずつ最適化してきました。

- 非同期コミュニケーションを主軸に、無駄な会議を減らす
- ドキュメントファーストで、コードレビューをより丁寧に
- 集中できる時間は、オフィスにいた頃よりも長くなった

**深入了解的技术**

- Vue 3 Composition API のソースコード
- React Concurrent Mode（正式版を待っているところ）
- Vite の ESM の仕組み
- フロントエンド監視システム（簡易的なものを自作）

## 2020年に完成できなかったこと

- アルゴリズムの練習：週 3 問を目標に、実際は月平均 5 問（😅）
- OSS への貢献：いくつか issue を挙げたが、実質的な PR は出せず
- 技術共有：チーム内で 3 回共有、目標の 6 回には届かず

## 最も影響を受けたこと

全面リモート＆非同期ワークへの移行を余儀なくされ、私はあることに気づきました。

**文章を書く力は、エンジニアにとって重要である。**

対面でのコミュニケーションはコストが低く、口調やボディランゲージで情報を補えます。文字でのやり取りにはそれがなく、物事を明確に説明しなければなりません。この 1 年で技術ドキュメントや設計ドキュメントをこれまでより多く書くようになり、かえってコミュニケーションの質が向上しました。

## 2021年の計画

技術：

- React 18 の新機能を深掘り（Concurrent Mode が正式になりそう）
- Vite 2 の本番実践
- アルゴリズムを体系的に学ぶ（本気で、毎日 1 問）
- 英語の技術書を読み始める（SICP）

エンジニアリング：

- チームのフロントエンド監視システムを構築する
- コンポーネントライブラリの整備を推進する

個人：

- ブログは月 4 本以上（更新を止めない）
- 体を鍛える（在宅で座りっぱなしは最悪なので）

2020 年は混乱のなかで過ぎましたが、混乱は成長の土壌でもあります。2021 年、頑張ろう。
