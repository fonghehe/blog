## 關於這個網誌

這裡收集前端開發的學習筆記、技術整理與實踐思路。文章以問題、適用條件及參考資料為線索，歸檔保留技術演進的背景。

作者公開帳戶：[fonghehe](https://github.com/fonghehe)。原始碼及問題回報：[GitHub 儲存庫](https://github.com/fonghehe/blog)。

## 內容維護說明 {#content-policy}

- 發佈日期保留歷史時間，後續修訂以更新日期另行標示，不把新增內容當作當年的結論。
- 驗證日期只在實際檢查相關行為後填寫；沒有該欄位不代表已驗證。適用版本說明文章討論的範圍。
- 歷史文章可能使用舊版本或已更改的 API，套用前請核對官方文件。
- 教學程式碼、假設情境與實際經歷須清楚區分；正式環境或效能結論需要具體環境、方法及證據。
- 歷史內容持續覆核中，部分文章仍有重複敘述、範例相關性及翻譯品質問題；今次網站改善不代表全部文章已完成驗證。

## 發現問題

歡迎透過文章留言或 GitHub issue 提供文章連結、具體段落、適用版本及官方參考資料。請勿公開憑證或個人資料。
